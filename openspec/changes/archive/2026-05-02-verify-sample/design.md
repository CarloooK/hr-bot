# Design: Verify Sample Change

## Approach
在 hr-bot 项目的 openspec/changes/ 下创建一个 verify-sample 目录，包含 proposal.md、design.md、tasks.md 三个文件，验证 OpenSpec 工作流目录结构完整。

## Architecture
```
openspec/changes/verify-sample/
├── proposal.md   # 变更提案
├── design.md     # 设计方案
└── tasks.md      # 实施清单
```

## Files to Change
- `openspec/changes/verify-sample/proposal.md` — 已创建
- `openspec/changes/verify-sample/design.md` — 本文件
- `openspec/changes/verify-sample/tasks.md` — 待创建

## Risks & Trade-offs
无。纯文档操作。
